В рамках всех паттернов рассматривается 4 основных способа взаимодействия:

1) File Transfer - передача файлов, например, через общую папку.
2) Shared Database - использование общей базы данных.
3) Remote Procedure Invocation (RPI) - приложения для взаимодействия вызывают функции друг друга, например, через REST или WSDL.
4) Messaging - взаимодействие черзе какой-то брокер сообщений, например Kafka или REST.

Часть паттернов трудно (или достаточно неадекватно) реализуются в некоторых способах взаимодействиях, поэтому, выбирая паттерны для реализации стоит учитывать здравый смысл.
