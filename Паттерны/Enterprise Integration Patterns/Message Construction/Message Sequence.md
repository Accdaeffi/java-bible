Иногда есть необходимость передать большой объём данных за раз, при этом небходимо соблюсти порядок или чётко указать на то, что передача происходит в рамках единой передачи.
В таком случае, используется паттерн Message Sequence - набор данных разбивается на множество сообщений, в каждом из которых идентификатор последовательности и номер в ней. 
Дополнительно либо отправляется общее количество сообщений, либо флаг окончания последовательности (в последнем сообщении).

Звучит странно и непрактично, иногда может принимать странные формы (например, при использовании File Transfer или Shared Database), но, активно используется под капотом RPI в рамках протокола IP (на котором работет TCP/IP).
