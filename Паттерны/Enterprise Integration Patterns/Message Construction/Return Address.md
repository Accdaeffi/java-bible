В паттерне Request-Reply иногда возникает проблема - отправленное сообщение требует ответа, но получатель не знает, куда его отправить.
Для решения её существует паттерн Return Address - отправленные сообщения включают в себя адрес ответа.

На первый взгляд это может показаться сложным и редко используемым, по факту на этом основан весь REST.
