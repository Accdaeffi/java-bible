Иногда информация, которую передаёт Message - это просто данные, без малейшего пояснения, что с ней делать. Подразумевается, что получатель сам должен знать необходимый порядок операций.
В таком случае говорится, что используется паттер Document Message.

Если кратко: это обычный Message, у которого в теле - данные.

Достаточно близкий, но во многом противоположенный шаблон - Command Message, где внутри сообщения передаются только команда, которую надо выполнить.
