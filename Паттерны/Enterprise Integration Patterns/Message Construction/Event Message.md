Подтип Message, который передаёт информацию о каком-то событии.
Обычно используется для синхронизации нескольких систем.

Ключевая характеристика - скорость доставки. Обычно таких сообщений много и они должны быть обработанны в кратчайшие сроки.
Паттерн хорошо сочетается с паттерном Message Expiration и плохо - с Guaranteed Delivery.
